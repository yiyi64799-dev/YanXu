# 研序桌面版 2.3.1 预览

本轮优先电脑独立使用。启动程序为 `YanXu.exe`；源码入口为 `yanxu_desktop.py`。
无需 Supabase 账户，也不需要联网。旧版入口、Android 代码和云端数据没有改动。

## 日常使用

- 今日：显示已到开始日期的未完成任务（包含逾期任务），重点与其他安排不重复。任务较多时只滚动列表。
- 新建任务：填写名称、开始日期、目标完成日，项目可不选。“更多选项”包含数字时间控件、提醒、状态和备注。
- 单击任务标题打开居中详情窗口，不挤压首页；长标题在列表显示两行摘要，详情和多行编辑保留完整内容。直接点击圆圈完成，底部支持撤销上一次完成或删除。删除采用标记，不直接清除记录。
- 任务页支持搜索和完成状态筛选；日历按所选日期显示跨日任务。
- 专注：开始、暂停、继续、结束，按实际计时保存时长。正常退出也会保存当前计时；异常断电尚不能恢复正在计时的片段。
- 设置：正文大小、列表密度、通知、关闭到托盘、数据导出与恢复。
- 项目：展示目标、下一步和关联任务完成情况。
- 知识卡片（原“复习”）：记录问题、答案、来源，可关联项目；先回想再查看答案，选择“记住了 / 还模糊”安排下次自测。旧记录完整保留，没有答案的旧条目可通过编辑补充。它不是每日习惯打卡，日常行动应记为任务。
- 成长记录（原“回顾”）：自动汇总本周完成任务、专注时间和关联项目，按天显示节奏；可记录心得并复制本周进展用于组会。缺失完成时间的旧任务不推测完成日期；没有数据时不编造统计。
- 轻量起步：从已到开始日期、可执行且预计不超过 15 分钟的任务中挑一项；优先近期截止，再按时长排序。只是建议，点击后先看详情，不自动改任务或启动专注。
- 提醒需要程序保持运行；可启用关闭到托盘。完全退出、关机或睡眠期间不能保证送达提醒。

## 数据安全

默认位置为 `%LOCALAPPDATA%\YanXu`：

- `desktop.sqlite3`：新的本地数据库，写入使用事务。
- `desktop-settings.json`：桌面外观设置，独立于旧账号设置。
- `backups`：每日首次启动的数据库快照、首次迁移的旧缓存副本，以及恢复前快照。

首次启动时只导入本机已有 `v2-cache.json`，保留旧记录 ID、旧缓存和未同步操作；以后不会重复导入覆盖桌面新数据。
如果有尚未下载到本机的云端数据，本版不会自动获取，请保留旧版，不要删除原缓存。
本版新增修改不会同步到手机。恢复云同步前需要单独设计数据合并，不能直接用旧版覆盖新库。

日常备份请使用“设置 → 导出数据备份”，生成可恢复 JSON，不包含账号令牌。
恢复会替换本地业务数据，必须确认，替换前自动生成 SQLite 快照。请定期把导出文件复制到另一块磁盘。
自动备份暂不自动删除，避免误删重要历史数据。

## 本轮范围

今日、任务编辑与详情、本地数据、完成撤销、日历筛选、专注计时已接入新版。
项目补充目标展示；知识卡片、成长记录基于原复习和回顾记录升级，没有删除旧条目。收集箱继续保留捕获和转任务。
自动安装更新暂时关闭，避免云端旧版本覆盖本地优先版本。不要把本预览版写入现有跨端 manifest。
原有重复规则保留，但本轮不自动生成重复任务。

## 开发与验证

使用包含 PyQt5 的 Python 运行 `python yanxu_desktop.py`。
测试：`python -m unittest discover -s tests -v`。
打包：`python -m PyInstaller --distpath release-desktop-preview --workpath build-desktop-preview YanXuDesktop.spec`。
测试使用独立目录，不访问真实账户。截图和测试夹具保留在 `artifacts` 下，不自动批量删除。
